# Aluminum Falcons Website

This is the team website for the 17230 Aluminum Falcons. 

## How to access
Click this link. Simple: [Aluminum Falcons Website](https://aluminumfalcons.com)

## Features
- Load in from hyperspace with a reactive starfield background.
- Sleek theme and color palette matching Starwars.
- Responsive stats, graphics, images, and scrollbars.
- Up-to-date team information.
- Functioning join form.

Built with React + Vite
